# Security policy

Tack is local-first and does not require an account or a network service. Do not report a vulnerability with private board data, captures, OCR text, or credentials attached.

For a security issue, use a private GitHub Security Advisory for the repository owner rather than opening a public issue. Include the affected version, a minimal reproduction, and the impact. Allow time for a fix before public disclosure.

The project does not promise a security response time while it is in alpha.
